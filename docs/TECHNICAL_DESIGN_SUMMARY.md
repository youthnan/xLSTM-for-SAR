# PI-xLSTM 轨迹误差校正系统 — 技术方案总结

## 1. 系统参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 载频 | 9.6 GHz | SAR 雷达 |
| 飞行速度 | ~10 m/s | 六旋翼无人机 |
| 飞行高度 | **~300 m** | （非 400m） |
| 斜距 | **~1000 m** | 地面距 ≈ 954 m |
| 场景尺寸 | **100m × 100m** | X（沿航迹）× Y（跨航迹） |

### 几何分析

- 掠射角 ≈ 17.5°，高掠射角场景
- ∂R/∂Y ≈ 0.95（Y 轴强约束）
- ∂R/∂Z ≈ 0.30（Z 轴弱约束，天然受限）
- ∂R/∂X ≈ 0（正侧视 broadside 盲区）

---

## 2. 网络架构

- **单头 Bi-xLSTM**（已弃用 v20 Cascade 双头）
- 4 个 xLSTM block：mLSTM → sLSTM → mLSTM → mLSTM
- 权重共享双向：同一组参数处理正/反向序列
- 输入 12 维 → hidden_dim 128 → 输出 3 维 δ_pred

### 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 单头 vs 双头 | 单头 | Cascade 精修无增益，多损失冲突 |
| 相位表示 | 真实解缠相位 | ∂φ/∂R = const，学习近线性 |
| V_raw 保留 | 是 | 代价可忽略，GPS 中断时互补 |
| use_input_mask | Stage 2 开启 | 实测有缺失通道，需区分 0 vs 缺失 |

|----|----------|----------|--------|----------|----------|

### 最少需要几个点？

- Z 轴不由点多决定——靠 **Phase 相位**和 **IMU 速度 V_raw**

## 4. 输入与损失的分工设计

核心设计原则：**输入给「状态」，损失给「约束」。**

```
输入层（告诉网络"当前是什么状况"）
├── P_raw, V_raw        → 导航状态
├── R_obs               → 雷达实测距离（绝对锚定）
└── ‖P_raw-Pos‖ − R_obs → 导航误差直接暴露

损失层（告诉网络"你的输出必须满足什么物理规律"）
├── L_MSE    → 监督 δ 对齐真值
├── L_RCM    → 约束修正后斜距一致（粗尺度，~cm）
├── L_phase  → 约束修正后相位一致（精细，亚 mm）
└── L_smooth → 约束时序平滑
```

### 为什么 R_obs 作为输入、Phase 作为损失（而非反过来）

| 考量 | R_obs 作为输入 | Phase 作为输入 |
|------|---------------|---------------|
| 解缠依赖 | **不需要解缠**，峰搜即得 | **必须先解缠**，解缠本身依赖 R_obs → 循环依赖 |
| R_ref 依赖 | 绝对量，与参考系无关 | 相对于 R_ref，不同点 φ 值差 5 个数量级 → 额外学习负担 |
| 量纲匹配 | 米，与 P_raw/V_raw 同量纲 | rad，10⁴–10⁵ 量级，与其他特征差 5 个数量级 |
| 噪声特性 | cm 级高斯白噪声 | 亚 mm 精度，但解缠错误 = λ/2 跳变（1.5cm 阶跃） |
| 物理含义 | "雷达测到这么远" | 需要配合 R_ref 才能还原距离 |

**Phase 放在损失里是最优位置**：1-cos 损失天然容错 2π 模糊，∂φ/∂R = −4π/λ = const（常数梯度，学习近乎线性），而放在输入层会引入解缠错误、R_ref 依赖和量纲错乱。

## 5. 输入特征（12 维）

| 索引 | 内容 | 来源 | 缺失时 |
|------|------|------|--------|
| 0–2 | 导航轨迹（高斯平滑）| GPS/IMU | 永不缺失 |
| 3–5 | 数值微分速度（高斯平滑）| diff(P_raw)×PRF | 永不缺失 |
| 6–8 | SAR 实测斜距 R_obs | SAR 回波峰搜 | 0, mask=0 |
| 9–11 | 导航-RCM 残差 | ‖P_raw−Pos_ref‖−R_obs | 0, mask=0 |

Stage 2 开启 `use_input_mask` 时，额外拼接 12 维 mask（标记每维有效/缺失），共 24 维入网。

## 6. 损失函数

### 6.1 RadarPhysicsLoss（仿真预训练 + 半监督）

| 损失项 | 公式 | 作用 | 坐标空间 | 有效条件 |
|--------|------|------|----------|----------|
| L_MSE | ‖δ_pred − δ_true‖² | 监督 δ 对齐真值 | 归一化 | has_label=True |
| L_RCM | ‖‖P_fix−Pos_ref‖ − R_obs‖² | 斜距一致性物理锚定 | 归一化（除以 err_std²） | rcm_weight > 0 |
| L_smooth | ‖δ[t]−δ[t-1]‖² | 时序平滑，抑制逐帧跳变 | 归一化 | 始终 |

RCM 归一化：L_rcm_norm = L_rcm_raw(m²) / mean(err_std²)，使 λ_rcm=1.0 表示 RCM 与 MSE 等权重。

### 6.2 PhasePhysicsLoss（v4_phase 数据）

$$L_{phase} = \frac{1}{N} \sum \left( 1 - \cos(\phi_{obs} - \phi_{ideal}) \right)$$

- φ_ideal = −4π·(‖P_fix−Pos_ref‖ − R_ref) / λ，在物理弧度空间计算，不归一化
- 相位差先 wrap 到 [−π, π] 再计算 1−cos 损失
- **1−cos 天然容错 2π 模糊**，解缠错误不会导致梯度爆炸

### 6.3 半监督行为

```
仿真样本（has_label=True）:
  L_total = L_MSE + λ_smooth·L_smooth + λ_rcm·L_RCM

实测样本（has_label=False）:
  L_total = λ_smooth·L_smooth + λ_rcm·L_RCM    （MSE 梯度为 0）
```

### 6.4 Phase 与 RCM 的互补关系

| | RCM 距离约束 | Phase 相位约束 |
|------|-------------|---------------|
| 精度 | ~cm | 亚 mm |
| 失败模式 | 峰搜 SNR 不足时野值 | 解缠 2π 错误（1.5cm 阶跃） |
| Z 轴敏感度 | ∂R/∂Z≈0.30（弱） | ∂φ/∂Z 显著（强） |
| 互补性 | 提供绝对尺度锚定 | 提供精细梯度方向 |

**RCM 失败时 Phase 兜底，Phase 解缠错时 RCM 兜底** —— 两种约束失败模式正交。

## 7. 训练策略

```
Stage 1：仿真预训练
├── 数据: 5000–10000 条仿真样本（全标签）
├── 损失: RadarPhysicsLoss or PhasePhysicsLoss
├── 目标: ValRMSE < 2cm
└── 输出: best.pt

Stage 2：半监督微调
├── 数据: 仿真 80% + 实测 20% 混合
├── 参数: use_input_mask=True, λ_rcm=3.0–5.0
├── 目标: 仿真不退化 + 实测成像改善
└── 输出: best_semi.pt

Stage 3：可选纯实测自监督
├── 损失: 仅 RCM + Smooth + Phase
├── 风险: 无标签可能漂移
└── 验证: SAR 图像 Sharpness / Entropy / Contrast
```

### random_ref_mask

训练时随机保留参考点（40%/30%/30% 概率保留 1/2/3 点），模拟实测中可能只有 1 个角反射器可用的场景。

## 8. 实测管线

```
GPS/IMU → P_raw → 高斯平滑
SAR 回波 → 脉冲压缩 → 峰搜 → 二次插值 → R_obs [T,3]
SAR 相位 → R_obs 距离辅助解缠 → φ_unwrapped [T,3]
                    │
                    ▼
        组装 12 维特征 + feat_mask
                    │
                    ▼
        网络前向 → δ_pred → P_fix = P_raw − δ_pred
                    │
                    ▼
        SAR 后向投影成像 → Sharpness / Entropy / Contrast 评估
```

## 9. Z 轴约束策略

远场几何下 ∂R/∂Z ≈ 0.30 天然弱，100m 场景内所有参考点 ∂R/∂Z 均在 0.29–0.31 范围内，**多点几何无法解耦 Z 轴**。Z 轴约束靠物理约束层：

| 手段 | 所属层 | 机制 |
|------|--------|------|
| Phase 相位（损失）| 约束层 | λ=3.1cm，∂φ/∂Z 显著，亚毫米精度 |
| IMU 速度 V_raw（输入）| 状态层 | GPS 中断段短期 Z 积分仍可靠 |
| Z 平滑正则（损失）| 约束层 | ‖Z[t]−Z[t-1]‖² 抑制高频振荡 |

这与 §4 的设计原则一致：**Z 轴不靠输入层给答案，靠约束层引导网络学到正确映射。**
